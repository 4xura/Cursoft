# 🏠 Главная — галерея пресетов

## 📦 Галерея — показывает все ваши пресеты курсоров.
- ЛКМ по пресету — применить курсоры.
- ПКМ по пресету — меню (изменить, переименовать, переместить влево/вправо, скачать, удалить, добавить в группу).
- Значок 🧩 — часть ролей взята из других пресетов.
- Перетащите плитку на другую — изменить порядок пресетов.
- Ctrl+клик по плиткам — выделить несколько пресетов, затем выбрать цвет и имя внизу, чтобы создать группу. Клик по плитке группы — свернуть/развернуть колоду; ПКМ — случайный выбор, изменить, собрать ячейки, разгруппировать или удалить.
- ПКМ по пустому пространству доски — «Создать группу» открывает диалог для создания пустой группы.

## ➕ «Добавить пресет» — создать новый пресет.
- Перетащите .cur/.ani файлы или папку прямо в окно.

## 🎨 Размер сетки — меняет размер ячеек галереи.
Выберите размер и способ масштабирования, затем нажмите «Применить». Можно использовать масштабирование Windows, сгладить контуры или сохранить чёткие пиксели.
↩️ «Назад» — откатить к предыдущему набору курсоров.
🌙/☀ — переключить тёмную/светлую тему.
🌐 — сменить язык интерфейса.
🔍 −/+ — масштаб интерфейса.
{img:OpenFolderIcon32} Иконка папки — синяя = папка «Загрузки» открывается после скачивания/экспорта; серая = отключено.
{img:DownloadIcon32} Экспорт — выбрать пресеты и сохранить их файлом (.cursoft, полностью импортируется обратно) или обычным ZIP-архивом (исходные файлы курсоров); сохраняется в «Загрузки».
{img:ImportIcon26} Импорт — выбрать файл пакета/архива Cursoft (или перетащить его на окно) и отметить, какие пресеты добавить.
Нажмите на название Cursoft, чтобы открыть сведения о приложении.
Запускать Cursoft в системном трее при входе в Windows.
🖱️ ПКМ по плитке «Стандарт» — скачать системные курсоры в «Загрузки» (PNG+GIF или .cur/.ani).
ⓘ Кнопка справа сверху — справка по окну.
🖱️ Клик по синей иконке курсора в названии приложения — применить случайный курсор со всей доски.
